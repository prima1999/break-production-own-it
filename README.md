A program that writes the one line an AI agent prints the instant it breaks production: a brutally honest confession of what it did, under 200 characters.

## Run it

```sh
node main.ts
```

The program writes the line to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that is set).
